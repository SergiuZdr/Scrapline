# Iteration 018 — Models, second pass: the user's notes on the proof

**Status:** in progress
**Started:** 2026-09-29 · **Finished:** —
**Answers:** the user on 017's proof: "the new Brute look is better but still not quite what I
wanted" -- **the concept has a lot of rounded sides, the game's version looked like a Lego/Roblox
character with very blocky parts; the parts don't have to be different colours, I want each part
to have more than one colour**; wants the concept's detail and heavier proportions. And "the
workshop in the concept looked very good but the cleaned version made it look like a yellow
brick with no details" -- the user made a Hugging Face account and asked for TRELLIS to be run
**in their Chrome browser**.

## Goal
The Brute looks like its concept -- rounded, detailed, heavy, several colours in every part --
and the workshop keeps the concept's detail, generated by TRELLIS with the user's account; both
still behind `--models new`, for the user to judge again.

## Scope
- In:
  - **The Brute, rounded**: every armour piece a rounded box (a multi-segment bevel shaded
    smooth, flat faces kept flat by weighted normals), domes and drums where the concept has
    them; no sharp-cornered block anywhere a player sees.
  - **The concept's detail, at sizes ink can draw**: panel seams, bolts, a domed head with a
    lens hood and antennae, knee and shin plates, a hand gripping the hammer, the saw's motor
    and guard; each detail at least a line's width at garage distance.
  - **Heavier proportions**: bigger pauldrons and forearms, thicker legs, bigger feet.
  - **Several colours in every part**: a new neutral `steel` zone (joints, frames -- not tinted
    by the livery, unlike `metal`) and a `trim` zone (the livery's accent colour), beside
    `paint`, `dark`, `alu` and `rust`. Both only exist on new models, so the shipped roster is
    untouched.
  - **Proposal, only under `--models new`: livery by MAKER** instead of by part id. Kessler
    Mining is mining yellow with orange trim (the concept's Brute), Cinder Foundry oxide red,
    Vektor Ballistics olive, Arclight Electric primer grey. A scavenged arm still does not match
    its frame unless it is the same maker -- and a maker SET (011) becomes visible at a glance.
  - **The workshop through TRELLIS**, driven in the user's Chrome (their logged-in Hugging Face
    account), from the same concept; then a clean-up that **keeps the detail**: no voxel remesh,
    no flattening into five colours -- the generated texture stays, drawn with the ink toon
    ramp and line.
- Out (deliberately): other machines and sites; changing the default game; generating the Brute
  (the user kept machines on route A).

## Steps
1. TRELLIS in the browser: the workshop concept -> GLB (and a second seed if the quota allows).
2. Clean-up in detail-keeping mode (`clean_generated.py --keep-texture`): level, seat, scale,
   a gentle decimation, the texture kept; the map dresses it with a textured toon + ink line.
3. The Brute rebuilt: rounded pieces, detail, proportions, the new zones; maker livery behind the
   flag; checks; pictures.
4. Shots (garage, board, map) and a sheet against 017 and the concepts; suites; docs.

## Acceptance criteria
- [ ] `verify_assembly -- --dir res://art/parts_new` and `verify_animation -- --models new` pass.
- [ ] No piece of the new Brute is a sharp-cornered box; every part shows at least three colours
  in the garage shot.
- [ ] The workshop is TRELLIS's, on the map, with its door, crane, drums and signage still
  readable at the map's closest zoom.
- [ ] Every suite passes; the default game is unchanged.
- [ ] The user judges it.
