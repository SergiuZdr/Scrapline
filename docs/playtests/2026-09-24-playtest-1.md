# Play-test 1 — 2026-09-24 (the user, after Iteration 004)

The first human play of the full loop. Recorded as said, grouped, and each issue given an
id so iterations can reference it (`PT1-3`, ...).

## Issues

| Id | Area | What the user said (paraphrased closely) | Severity |
|---|---|---|---|
| PT1-1 | Combat | **Battles feel like a boring chore after two fights.** Little thought is needed, and it is not pleasing to look at. No distinctive feature makes the gameplay interesting | **Critical**: the core loop |
| PT1-2 | Combat | Weapons only fire in straight horizontal/vertical lines. With an enemy on a diagonal tile after moving, nothing can hit it, even with reach 5 | High |
| PT1-3 | Combat | The Crawler is the only ally objective and it is unclear what it is for, beyond the enemy wanting to destroy it | High |
| PT1-4 | Combat | Death animation feels bad. It is unclear why nothing can stand where a robot died. Suggestion: **a scrap pile that either team can pick up** | Medium |
| PT1-5 | Combat | Attack and move animations feel laggy | Medium |
| PT1-6 | Run | **It does not feel like a true roguelike.** After each room nothing really upgrades the team. New parts are often not better. No perks, no sets, nothing that makes a build strong enough to clear the last rooms | **Critical**: the run loop |
| PT1-7 | Onboarding | Names and jargon are explained nowhere. A tutorial at the start would solve most of it | High |
| PT1-8 | Map | The map screen is awful: the map itself, and the Reclaimer. You cannot tell when you must move forward and when you can move sideways | High |
| PT1-9 | Refit | Want to pick a part up and drag it onto where it should go. DONE is confusing: it reads as "done with this one part" | Medium |
| PT1-10 | Map | The log on that screen has no reason to be there | Low |

## What this says about the process

- The bot measured stakes (win rate, loss causes) and could not measure fun, clarity or
  feel. Three iterations passed without a human play. **From now on, every iteration that
  changes how the game plays ends with the user playing it.**
- Pressure (003) was solved by adding a thing to protect, not by making decisions
  interesting. Stakes without choices is the chore the user describes.
