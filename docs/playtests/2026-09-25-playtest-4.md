> "It is a nice jump forward, but the game needs desperately the next 3 iterations and a
> visual level-up overall (from UI to models, for EVERYTHING)."

The user asked for the art to be sourced or made with the best available tools ("skills"),
and for their output to be judged, not assumed. That work is `plans/art-sourcing.md`.

The next three iterations on the roadmap (build progression, onboarding, Act 1 content),

## Diagnosis
- **PT4-9 is a real rule problem.** A hex line that passes exactly between two hexes is
  broken by a fixed nudge in `Hex.line`, so it always leans the same way, whatever is on
  that side. The fix is to try both leanings and take the clear one — for both teams, in
  `strike_plan`, so previews, the AI and execution agree.
- **PT4-12, "why does it move":** every second round a hive marks a free hex NEXT TO
  ITSELF (`CombatSim._hives`), then walks away in the same enemy phase. The drone lands on
  the mark the round after, and the next mark appears beside wherever the hive has walked
  to — so the build site seems to wander, and nothing on the tile counts down.
- **PT4-3:** each machine's parts are `.glb` files loaded on first use, synchronously, and
  a SubViewport shows black until its first frame is drawn.
