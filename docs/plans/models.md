# Plan — Models: three routes to pick from (play-test 6, PT6-5)

**Status:** proposal, 2026-09-29, for the user to choose. The user: "the game still needs all
its models for the entire map and robots, done from the beginning, or found on the internet,
or generated (e.g. with ChatGPT) and then turned into Blender models."

## What any model must satisfy

- **Machines are modular.** A machine is five parts -- chassis, core, two arms (the arm IS the
  weapon), module -- bolted together at named sockets (`socket_core`, `socket_arm_l/r`,
  `socket_module`); arms are torn off in fights, levels bolt armour on, a salvaged arm must fit
  any frame. Every part carries material ZONES (`mat_paint`, `mat_metal`, `mat_dark`, ...),
  legs are child objects pivoting at the hip, and `verify_assembly.gd` checks the export. A
  model that is one fused mesh is not a machine until it is cut into those parts.
- **Ink & Rust punishes small detail.** Every mesh gets an ink line at a constant screen width,
  so a bolt, a greeble or a noisy scanned surface becomes a black speck or a scribble at 40 px.
  What reads is big shapes, a clear silhouette per role, and few, large panels.
- **Sites and the Reclaimer are one-off set pieces**: no sockets, no tearing, seen from far
  above. They are the easy half.
- **The game is sold**: every source needs a licence that allows commercial use.

## Route A — rebuild the generator's part library from concept art (made here)

Concept sheets first (drawn in the ink style -- or generated by the user with an image model, as
the user suggested), then the Blender generator (`tools/blender/scrapgen/`) is reworked to
build those shapes: chunkier silhouettes per role, bigger plates, fewer small parts. Sockets,
zones, legs, exports and every check stay automatic.

- For: the socket contract by construction; one consistent hand; any number of variants; nothing
  to license; the checks that exist keep working.
- Against: it is the slowest route to shapes with real character, and it is where "generated
  boxes" came from -- it only works if the concept art leads.

## Route B — adapt open-licence kits (CC0)

Quaternius's mech and robot packs and Kenney's and KayKit's kits are CC0 (free, commercial use
allowed, no credit required), low-poly and consistent within a pack.

- For: authored shapes today; free; low-poly already suits ink.
- Against: whole characters, not five-slot machines -- each must be cut into parts, socketed and
  zoned by hand; they look like the many other games that use the same packs; mixing packs
  breaks the one-hand look.

## Route C — generate them (concept image -> image-to-3D -> Blender)

A concept image (ChatGPT or any image model) turned into a mesh by an image-to-3D service, then
cleaned in Blender: decimated, cut into parts, socketed, zoned.

- Tripo and Meshy (hosted): the free tiers are non-commercial or CC BY; a paid plan
  (roughly $12-20 a month) is needed for a sold game. Clean enough to start from.
- TRELLIS 2 (open, MIT licence): the best open quality, but it needs a 24 GB NVIDIA card -- this
  Mac cannot run it; a rented cloud GPU can.
- Hunyuan3D (open): its community licence does not apply in the EU, UK or South Korea.
- For: unique designs, fast; strong for set pieces.
- Against: one fused, dense, noisy mesh per image -- the most hand work per machine part, and a
  noisy surface draws as scribble under the ink line unless decimated flat.

## Recommendation: a hybrid, proved on two models first

- **Machines: Route A, led by concept art.** Modularity is the game (tearing, levels, salvage),
  and only the generator keeps it for free. The concept sheets are where the character comes
  from -- the user can generate them, or they are drawn here in the ink style.
- **Sites and the Reclaimer: Route C or B.** Set pieces need no sockets, so a generated or kit
  model only needs cleaning and zoning, and each one is a single job.
- **Prove it first**, as the style frame did: one machine (the Brute: a chassis, both arms, a
  core) through route A, and one landmark (the workshop) through route C, side by side in the
  game, before the rest of the roster.
